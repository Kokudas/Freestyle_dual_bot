# FSR 내전봇 · Cloudflare Workers v2.0.0

기존 Python v1.6.1 봇의 내전 기능을 HTTP 방식으로 옮긴 배포본입니다. PC나 디스호스트에서 봇 프로세스를 계속 실행할 필요가 없습니다. Discord의 슬래시 명령과 버튼을 Workers가 받고, 내전 데이터는 D1에 저장합니다.

**설치 순서는 [CLOUDFLARE_GUIDE.md](CLOUDFLARE_GUIDE.md), 기존 DB 이전은 [MIGRATION_GUIDE.md](MIGRATION_GUIDE.md)를 먼저 읽어주세요.** 이 ZIP은 디스호스트에 덮어쓰는 파일이 아닙니다.

## 포함된 기능

- `/내전열기` → 랜덤 편성 또는 직접 편성 → 종료 방식 선택
- 랜덤 편성: 최대 팀 수 → 주 역할 우선 → 부족한 역할만 보조 충원 → 동률 무작위 → 남는 인원 대타
- 직접 편성: 참가자가 TEAM 1~20과 역할 선택, 자리 중복 방지, 미완성 팀 확정 방지
- 1회 풀리그 / 전체 최대 판수 / 목표 승점, 종료 기준 달성 시 자동 종료
- 팀장 결과 제출 → 상대 팀장 확인, 불일치 시 운영진 판정
- 대타 교체, 팀장 변경, 팀 기권, 승점 수정, 마지막 결과 취소
- 기존 대기실·팀 음성방 연결, 팀별·역할별·대기실 이동
- 주·보조 역할 인원 수와 명단을 구분한 현황 패널
- 복수 운영진 역할 및 여러 Discord 서버 지원
- 종료된 봇 현황 패널 자동 삭제, 기본 60분
- `/제비뽑기 후보:철수, 영희, 민수`

느낌표 명령은 `/제비뽑기`로 바뀝니다. Message Content Intent와 Gateway 상시 연결은 사용하지 않습니다. 봇은 Discord에서 오프라인으로 보일 수 있지만 슬래시 명령과 버튼은 동작합니다.

## 혼잡 시간 처리

신청·결과 처리는 D1에 작업을 저장한 뒤 처리합니다. 같은 Discord 요청이 다시 도착해도 승점을 중복 지급하지 않습니다. 동시에 상태를 수정하면 최신 기록을 다시 읽어 반영합니다. 공개 패널은 짧게 갱신을 모으고, 음성 이동은 8명씩 처리합니다. 일시적인 실패는 저장된 작업과 1분 주기 점검으로 재시도합니다.

이는 지연을 줄이기 위한 구조이며 실제 응답 시간은 Cloudflare 요금제, D1 부하, Discord API 제한의 영향을 받습니다. 무료 요금제의 무제한 사용이나 무지연을 보장하지 않습니다. 대규모 내전은 시험 운영 후 Workers Metrics에서 CPU 초과·오류를 확인하세요.

## 파일

| 파일 | 용도 |
| --- | --- |
| `wrangler.jsonc` | 앱 ID, 공개키, D1 ID, 채널 이름, 운영진 역할 설정 |
| `src/` | Workers 코드 |
| `migrations/0001_initial.sql` | 새 D1 테이블 생성 |
| `scripts/register-commands.mjs` | 슬래시 명령 등록 |
| `scripts/migrate_sqlite.py` | SQLite 백업을 D1 가져오기 SQL로 변환 |
| `.dev.vars.example` | 로컬 토큰 설정 예시 |
| `tests/` | 규칙·Workers·D1·이전 도구 검증 |

`npm ci`로 의존성을 설치합니다. Node.js 22.9 이상(24 권장), 이전 도구·전체 테스트는 Python 3.10 이상이 필요합니다. Python이나 npm은 설치·검증하는 컴퓨터에서만 사용하며, 배포 후에는 켜둘 필요가 없습니다.

검증 명령:

```sh
npm run check
npm test
npx wrangler deploy --dry-run
```

## 데이터와 채널

음성채널 생성·삭제·권한 변경은 하지 않습니다. 자동 정리는 이 봇이 추적하는 종료 현황 메시지만 지우며 일반 채팅과 경기 DB는 유지합니다. `/내전상태`·관리 응답은 기본적으로 실행한 사람에게만 보입니다.

같은 Discord 앱의 명령을 이 봇이 일괄 등록하므로 다른 봇 기능을 같은 앱에 추가해 사용 중이라면 등록 스크립트에 해당 명령을 합쳐야 합니다. 다른 Discord 앱에는 영향을 주지 않습니다.
